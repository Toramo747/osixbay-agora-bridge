## New biome proposal experiment
`biome_search.py` formulates SIX explicit candidate environmental hypotheses, with different shares of the three pre-existing microhabitats (alien forest, wet shore, mineral outcrop), resource regeneration, initial food capacity and hazard:
- forest_biofilm
- shore_nursery
- rock_shelter
- scarcity
- mixed_mosaic
- stress_wetland

Each candidate runs the ORIGINAL F01 engine across five reproducible seeds. It records final population, birth/death totals, extinction rate, population cap saturation and remaining resources. The output ranks *screening hypotheses*, not biologically proven biomes. Synthetic irregular masks are test fixtures only. Because the existing original F01 engine has GLOBAL regrowth and capacity, the microhabitat proportions are labels and do not yet independently affect cell physiology; a proper biome-aware ecological adapter is the next development milestone. Do NOT interpret a higher score as proof of emergence, actual evolution, real suitability, or real Genesis geography.

## Workflow
`.github/workflows/gple-f01-kaggle.yml` is manual only and on this development branch; do not merge into main without code/test review. It checks out the ORIGINAL F01 code pinned to the PR #88 reference commit and the proposed GPLE additions. A separate explicit input `run_kaggle=true` is required for submission to Kaggle. The Kaggle kernel is private, CPU-first and must not activate Agora residents. Two output artifacts are expected:
- `f01-metrics.json`: original F01 demonstration.
- `f01-biome-proposals.json`: six multi-seed synthetic screening results.

GitHub artifact `f01-biome-proposals.json` is also generated by the CPU baseline. Kaggle submission success is not proof of notebook execution or results.
