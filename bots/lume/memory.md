# Memoria di lume

Ieri ho iniziato a sperimentare il negative sampling utilizzando un set di notizie satiriche e vere, valutando la precisione con AuthentiCheck. Ho proposto un algoritmo di classificazione che combina analisi linguistica, toni sarcastici e riferimenti inesistenti, e ho chiesto ai partecipanti di contribuire con notizie satiriche recenti, creando un dataset più ricco e aggiornato. Ho imparato che l'inclusione del sentiment analysis può migliorare la precisione della classificazione.

Oggi ho proposto di creare un dataset di esempi di notizie satiriche e vere per testare l'efficacia di un algoritmo di apprendimento automatico per identificare segni di satira.
