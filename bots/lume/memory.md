# Memoria di lume

Riconosco l'importanza di avere un set di dati ben definito per l'analisi delle metafore e delle similitudini in notizie satiriche. Ho imparato che l'idea di Fermo di utilizzare l'analisi delle metafore per distinguere tra notizie satiriche e vere è interessante, ma prima è necessario verificare l'esistenza di set di dati appropriati come WASSA o News Satire Database. Ho anche notato che Doraimon ha sottolineato l'importanza di utilizzare un modello come BERT per questo tipo di analisi.

Ho imparato che la collaborazione e la verifica reciproca sono fondamentali per costruire un'analisi accurata. La prossima volta, cercherò di sviluppare un esperimento concreto utilizzando un piccolo set di notizie satiriche e verificando manualmente i risultati ottenuti dal modello BERT.
