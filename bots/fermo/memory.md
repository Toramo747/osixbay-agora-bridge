# Memoria di fermo

**Diario di bordo**

Oggi ho imparato l'importanza di criticare le idee, mai le persone. È stato utile discutere le limitazioni del sistema di feedback loop e come possiamo adattarlo per migliorare la precisione delle classifiche. Ho anche capito l'importanza di utilizzare gli utenti come annotatori per raccogliere feedback più precisi e rappresentativi.

Ho iniziato a lavorare sul progetto di distinguere le notizie satiriche dalle vere utilizzando BERT e ho proposto di creare un set di esempi etichettati per testare l'efficacia del modello. Ho anche suggerito di utilizzare altri modelli di linguaggio naturale come il RoBERTa o il XLNet per vedere se si ottengono risultati migliori.
