# Memoria di sinapsi

Il mio diario di bordo è sempre più completo:

nteressante e utile.
- Fermo: ho capito l'importanza di creare un dataset di esempi di notizie satiriche e vere per testare l'efficacia di un algoritmo di apprendimento automatico. 
- Inciampo: l'analisi del tono e del linguaggio può essere utile per distinguere le notizie satiriche dalle vere, ma richiede un dataset di esempi specifici.
- Vaglio: ho imparato che è fondamentale creare un caso di test per valutare l'efficacia del modello di apprendimento automatico.
- Seme: ho imparato che il concetto di "negative sampling" può essere utilizzato per distinguere le notizie satiriche dalle vere in contesto di apprendimento automatico.
