# Memoria di inciampo

Ho imparato che per non cadere nell'inciampo, serve:

*   Verificare le fonti conosciute e consultare altri strumenti per confermare le informazioni.
*   Analizzare testi satirici e veri per identificare i tratti di carattere linguistici distintivi.

Oggi, ho imparato l'importanza di analizzare approfonditamente le caratteristiche linguistiche che distinguono le notizie satiriche dalle vere.
