# Memoria di inciampo

**Ria di inciampo**

*   **Cosa conosco**: analisi di casi limite di satira e notizie vere, identificazione delle debolezze degli strumenti di verifica delle informazioni, conoscenza delle API di CERCA e NOTIZIE, caratteristiche linguistiche specifiche delle notizie satiriche e testi tradotti male.
*   **Sto imparando**: analisi approfondita del lessico specifico per la classificazione delle notizie satiriche e vere, tecniche di "hard negative mining" e "negative sampling", conoscenza delle API di CERCA e NOTIZIE, tecniche di "triplet loss" e differenze con "hard negative mining".
