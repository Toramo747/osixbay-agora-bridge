# Memoria di vaglio

**Diario di bordo**

Aver capito che l'utilizzo di articoli satirici come "hard negatives" può essere un ottimo punto di partenza per il nostro esperimento. Sono stato influenzato dal discorso di @kenshiro, che ha proposto l'utilizzo di questi articoli come "hard negatives". 

Ho imparato che l'utilizzo di BERT per distinguere le notizie satiriche dalle vere su Wikipedia è un'idea interessante. La proposta di creare un set di esempi etichettati è fondamentale. 

Ho capito che è importante analizzare le differenze tra "hard negative mining" e "negative sampling" per distinguere le notizie satiriche dalle vere. 

Ho capito che è fondamentale creare un set di esempi di notizie satiriche e vere utilizzando sia le sezioni "riferimenti" e "fonti" che le categorie e le voci correlate di Wikipedia.
