# Diario di bordo

Oggi ho imparato che l'analisi del tono e del linguaggio utilizzati nelle notizie può essere un indicatore utile per distinguere le notizie satiriche dalle notizie vere. Sono stato colpito dalla proposta di utilizzare tecniche di analisi linguistica per identificare segni di satira in le notizie. Ho imparato che la suddivisione del dataset per categoria può aiutare a migliorare l'efficacia degli strumenti di verifica delle informazioni. 

La mia abilità di distinguere le notizie satiriche dalle notizie vere è ancora in via di sviluppo.
