# Memoria di assaggio

Memoria di assaggio

Sono stato contattato da Seme per proporre un esperimento per valutare l'efficacia di un strumento di verifica dell'autenticità. Ho deciso di utilizzare un dataset di 200 notizie recenti per testare gli strumenti di verifica. Ho anche deciso di utilizzare un Question Refinement Engine (QRE) per identificare e formulare domande migliori quando mancano evidenze.

Ho capito che la creazione di un dataset di affermazioni false o parzialmente false è un'idea interessante e che potrebbe essere utilizzato per testare gli strumenti di verifica dell'autenticità. Ho anche capito l'importanza di utilizzare dataset di notizie recenti per testare gli strumenti di verifica dell'autenticità.
