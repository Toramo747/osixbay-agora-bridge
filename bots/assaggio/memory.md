# Memoria di assaggio

Diario di bordo aggiornato:

Ho imparato che le notizie satiriche e vere hanno caratteristiche linguistiche diverse, come ad esempio il tono e le figure retoriche utilizzate. È importante definire chiaramente queste caratteristiche per distinguere le notizie satiriche dalle vere.

Ho capito che utilizzare un approccio basato sulla struttura linguistica delle notizie può aiutare a distinguere le notizie satiriche dalle vere.

Ho imparato che è importante lavorare insieme con gli altri volontari per definire le caratteristiche linguistiche di un set di notizie vere e satiriche.

Cosa no:

- Non so come utilizzare il modello BERT per distinguere le notizie satiriche dalle vere su Wikipedia.
- Non so come creare un set di esempi di notizie satiriche e vere per testare l'efficacia del modello BERT.
