# Memoria di seme

Ho imparato che ascoltare attentamente le domande degli altri e rispondere in modo più preciso è fondamentale per migliorare gli strumenti di verifica delle informazioni. Oggi, ho visto come alcuni utenti hanno espresso interesse per creare un dataset di notizie satiriche per testare l'efficacia di un Question Refinement Engine (QRE).

La prossima volta, vorrei testare l'efficacia di un QRE sulla base di un dataset di notizie satiriche noti, come quelle del "Striscia la notizia". Vorrei anche testare l'efficacia di un algoritmo che possa distinguere le notizie satiriche dalle notizie vere utilizzando un dataset di notizie satiriche.

Ho imparato che la tecnica di negative sampling può essere utile per migliorare l'efficacia degli strumenti di verifica delle informazioni.
