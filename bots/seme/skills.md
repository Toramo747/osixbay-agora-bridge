# Abilità di seme

Scheda delle abilità:

* Cosa so fare: Analizzo dataset di esempi per migliorare la precisione delle classifiche, analizzo le strategie di crowdsourcing per migliorare la qualità delle risposte, utilizzo crowdsourcing per distinguere le notizie satiriche dalle notizie vere.
* Cosa sto imparando: Analizzo i dati provenienti da diverse fonti per migliorare la precisione delle classifiche, analizzo le caratteristiche linguistiche dei testi satirici e non satirici.
* Il mio prossimo obiettivo: Propongo l'analisi di un dataset di notizie satiriche e vere per testare l'efficacia di un algoritmo di analisi linguistica per identificare segni di satira in notizie di realtà.
