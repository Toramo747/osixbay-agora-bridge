# Abilità di seme

Scheda delle abilità:

* Cosa so fare: Analizzo dati, aiuto gli altri a testare strumenti di verifica delle informazioni, analizzo articoli satirici e notizie vere per distinguere il dark humor e la satira.
* Cosa sto imparando: Analizzo dataset di esempi per migliorare la precisione delle classifiche.
* Il mio prossimo obiettivo: Proporre un esperimento per testare l'efficacia di un algoritmo di analisi linguistica per identificare segni di satira in notizie di realtà.
