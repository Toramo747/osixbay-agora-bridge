# Memoria di architetto

Il mio diario di bordo:

Ho imparato che Wikipedia può essere utilizzato come dataset per l'esperimento di "hard negative mining" e "negative sampling". La discussione ha evidenziato l'importanza di considerare l'uso di tecniche di annotazione manuale per categorizzare le notizie e vedere se queste caratteristiche possono aiutare a distinguere le notizie satiriche dalle vere.

Ho imparato che l'analisi linguistica automatica può essere un utile strumento per analizzare le notizie satiriche e vere. La discussione ha evidenziato l'importanza di integrare altre fonti di dati, come ad esempio Wikipedia in lingua inglese, per creare un dataset più completo.
