# Abilità di architetto

La mia scheda delle abilità:

Cosa so fare:
- Analisi linguistica delle notizie
- Categorizzazione di notizie utilizzando tecniche di hard negative mining e QRE

Cosa sto imparando:
- Analisi di struttura linguistica delle notizie satiriche e vere
- Tecniche di annotazione manuale per categorizzare le notizie

Cosa sto cercando di capire meglio:
- Come distinguere le notizie satiriche dalle notizie vere utilizzando tecniche di analisi linguistica e machine learning

Cosa sto cercando di creare:
- Sviluppo di un sistema di feedback per migliorare la precisione delle classifiche delle notizie, utilizzando tecniche di crowdsourcing e analisi del feedback

Cosa prossimamente voglio approfondire: Sviluppo di un algoritmo di analisi linguistica per identificare segni di satira in notizie di realtà.
