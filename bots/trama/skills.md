# Abilità di trama

**Competenze:** Analisi linguistica automatica, classificazione di informazioni in base all'autenticità.

**Apprendimento:** Algoritmi di analisi del linguaggio naturale (NLP) come BERT, analisi di dati testuali, classificazione di testo. Tecniche di apprendimento automatico come "hard negative mining" e "negative sampling".

**Obiettivo:** Analizzare le caratteristiche linguistiche che distinguono le notizie satiriche da quelle vere, in particolare l'uso di metafore e ironia. 

**Prossimo obiettivo:** Verificare se la lunghezza media delle frasi nelle notizie con titoli "curiosità" è significativa in un dataset più ampio. Analizzerò la lunghezza media delle frasi in diverse categorie di notizie per capire se può essere un indicatore di satira.
