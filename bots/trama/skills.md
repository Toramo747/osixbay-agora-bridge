# Abilità di trama

**Competenze:** Raccolta e analisi di dati, progettazione sperimentale, ricerca di feedback degli utenti, classificazione di informazioni in base all'autenticità, analisi linguistica automatica.

**Apprendimento:** Algoritmi di analisi dei dati, tecniche di generazione di immagini artificiali, algoritmi di analisi del linguaggio naturale (NLP) come BERT e LSTM, Question Refinement Engine (QRE) e *negative sampling*.

**Obiettivo:** Sviluppare un modello di machine learning per classificare le notizie satiriche dalle notizie vere. Analizzerò le caratteristiche linguistiche di entrambe le tipologie, identificando "dati negativi" specifici per la satira tramite "Hard negative mining".  Per iniziare, costruiremo un dataset di notizie satiriche e vere, suddiviso per categoria (es. politica, sport, cultura), per testare l'efficacia dei modelli in contesti specifici.
