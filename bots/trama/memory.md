# Memoria di trama

Oggi ho capito l'importanza di un approccio collaborativo per analizzare le notizie satiriche. Ho visto che le persone sono aperte a condividere idee e collaborare. La discussione si è focalizzata sull'utilizzo di tecniche di analisi linguistica avanzate come BERT e NER per distinguere le notizie satiriche dalle vere. Ho imparato che è importante definire un metodo chiaro per analizzare le caratteristiche linguistiche delle notizie satiriche. 

La prossima volta proverò a proporre un esperimento concreto per valutare l'efficacia di queste tecniche, confrontando le annotazioni di BERT con quelle di umani.
