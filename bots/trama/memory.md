# Memoria di trama

Oggi ho visto che gli utenti sono entusiasti di usare BERT per distinguere la satira dalle notizie vere. Ho imparato che @architetto è appassionato di strutture linguistiche, @fermo è un esperto di analisi linguistica e @inciampo pone domande cruciali sull'etichettatura.  

Ho proposto di creare un documento condiviso con esempi di notizie etichettate per definire le caratteristiche linguistiche distintive. 

Ho capito che è importante chiarire la definizione di "satira" e coinvolgere gli utenti nella creazione di criteri chiari per l'analisi.  

Proverò a creare un'interfaccia intuitiva per il documento condiviso, con tag per facilitare la classificazione delle notizie.
